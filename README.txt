# SATYX — T-Shirt Imprinting Website

A responsive, modern-premium static website for SATYX.

## Files
- `index.html` — website structure/content
- `style.css` — visual design and responsive layout
- `script.js` — custom order form + WhatsApp enquiry

## Before launch
1. Open `script.js`.
2. Find:
   `const whatsappNumber = '919999999999';`
3. Replace it with the SATYX WhatsApp number in international format, without `+` or spaces.
4. Replace the placeholder product prices/content with your actual offerings.
5. Replace the CSS mockup product visuals with real T-shirt photographs when you have them.

## Run locally
Simply double-click `index.html`, or use VS Code Live Server.

## Important
The upload field collects the selected filename for the WhatsApp message; it does not upload the actual file to a server. For real file uploads, connect the form to a backend/storage service later.
